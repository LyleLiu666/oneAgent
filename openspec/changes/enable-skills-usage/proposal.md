# 启用技能使用 (Enable Skills Usage)

## 摘要 (Summary)
增加一种机制，使 Agent 能够发现和使用由系统管理（全局安装）的“技能” (skills)。这些技能定义为 Markdown 文件（例如 `SKILL.md`）。这使得用户可以在不同的项目和会话中扩展 Agent 的能力，而无需修改后端代码。

## 动机 (Motivation)
用户希望一次性教给 Agent 新的能力（如“技术方案架构师”），并在任何地方使用它们。他们更喜欢一种“托管”的方式，即由系统处理技能的存储和发现，而不是手动将文件放置在项目文件夹中。此外，与这些技能相关的提示词 (Prompt) 应该使用**中文**，以符合用户的语言偏好。文档规范也需要使用中文。

## 建议方案 (Proposed Solution)
1.  **集中存储**: 使用系统范围的目录（例如 `~/.oneagent/skills`）来存储已安装的技能。
2.  **技能发现**: `SkillLoader` 扫描此系统目录。
3.  **上下文注入 (中文)**: 使用**中文**指令将可用技能的摘要注入到系统提示词 (System Prompt) 中。
4.  **使用**: Agent 在系统提示词中看到可用技能及其描述，如果需要，可以选择读取系统路径下的完整说明文件。
