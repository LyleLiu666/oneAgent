# 设计: 启用技能使用 (Enable Skills Usage)

## 组件 (Components)

### 1. 技能发现 (`internal/skill`)
一个新的包，负责系统范围的技能管理。
- **存储位置**: `~/.oneagent/skills` (平台特定的用户配置目录)。
- **扫描**: 扫描存储位置中的 `*.md` 或 `*/SKILL.md`。
- **元数据**: 解析 YAML frontmatter（如果存在）或直接使用文件夹名称。

### 2. 上下文注入 (`internal/handler`)
修改 `ChatHandler` 以注入技能列表。
- **语言**: **中文**。
- **提示词模板**:
  ```text
  ## 可用技能 (Available Skills)
  以下是你可用的扩展技能。如果任务涉及相关领域，你需要先读取技能文件以了解具体的操作协议。
  
  - [技能名称]: [描述] (文件路径: [AbsolutePath])
  ...
  ```

## 数据流 (Data Flow)
1.  **启动**: 后端初始化 `SkillLoader`，指向系统/全局目录。
2.  **请求**: `ChatHandler` 获取技能列表。
3.  **提示词构建**: 将中文的技能摘要块追加到 `SystemPrompt`。
4.  **Agent 行动**: Agent 看到技能列表。如果任务匹配技能描述，Agent 对提供的系统路径使用 `view_file` 工具。

## 权衡 (Trade-offs)
- **用户体验**: 用户需要一种方式来“安装”技能。（本规范范围之外，但暗示了需要文件复制或未来的 `install` 命令）。对于 MVP，我们假设文件已存在于系统目录中。
- **更新**: 全局技能会影响所有项目。这是预期的行为。
- **路径访问**: Agent 必须对系统目录具有读取权限。
