# Backend 模块文档

docs/backend 下的文档按「模块」组织：每个模块一个文件夹，并拆成三类：

- `00-overview.md`：纵览（适合作为入口）
- `01-details.md`：细节（接口/结构/边界/异常/配置等）
- `02-design.md`：设计（流程图/状态机/关键设计取舍等）
